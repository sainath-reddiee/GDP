# Opportunity Domain Contract

Canonical contract for the `opportunity_core` silver iceberg SCD1 + HIST hub model.

Target table: `DEV_GDP_SILVER_DB.OPPORTUNITY.OPPORTUNITY_CORE` (147 columns).

---

## Required Mapping Keys (minimum)

When onboarding a new source, the `column_map` MUST cover at least:
- `source_unique_id`
- `opportunity_name`
- `stage_name` (drives `ref_opportunity_status`, `ref_opportunity_segment`)

## Reference CTE Block (paste into ephemeral model)

```sql
country_mapping as (
    select
        upper(trim(value_1)) as value_1_norm,
        target_value
    from {{ source('opportunity_shared_reference', 'gdp_country_mapping') }}
    where model_name = 'country_name_std'
),

ref_country as (
    select ref_country_skey, country_name
    from {{ source('opportunity_geo_reference', 'ref_country') }}
    where gdp_is_active = TRUE
),

ref_status as (
    select opportunity_status_skey, opportunity_status_desc
    from {{ source('opportunity_reference', 'ref_opportunity_status') }}
),

ref_deal_type as (
    select opportunity_deal_type_skey, opportunity_deal_type_desc
    from {{ source('opportunity_reference', 'ref_opportunity_deal_types') }}
),

ref_service_lines as (
    select opportunity_service_lines_skey, opportunity_service_lines_desc
    from {{ source('opportunity_reference', 'ref_opportunity_service_lines') }}
),

ref_category as (
    select opportunity_category_skey, opportunity_category_desc
    from {{ source('opportunity_reference', 'ref_opportunity_category') }}
),

ref_segment as (
    select opportunity_segment_skey, opportunity_segment_desc
    from {{ source('opportunity_reference', 'ref_opportunity_segment') }}
),

ref_business_line as (
    select opportunity_business_line_skey, opportunity_business_line_name
    from {{ source('opportunity_reference', 'ref_opportunity_business_line') }}
),

ref_selling_team as (
    select opportunity_selling_team_skey, opportunity_selling_team_desc
    from {{ source('opportunity_reference', 'ref_opportunity_selling_team') }}
),

ref_global_region as (
    select ref_global_region_skey, global_region_name
    from {{ source('opportunity_geo_reference', 'ref_global_region') }}
),
```

## Reference JOIN Block (paste into base CTE FROM clause)

```sql
left join country_mapping as cm
    on upper(trim(o.lead_country)) = cm.value_1_norm
left join ref_country as cntry
    on upper(trim(coalesce(cm.target_value, o.lead_country))) = upper(trim(cntry.country_name))
left join ref_status as st
    on upper(trim(o.stage_name)) = upper(trim(st.opportunity_status_desc))
left join ref_deal_type as dt
    on upper(trim(o.deal_type)) = upper(trim(dt.opportunity_deal_type_desc))
left join ref_service_lines as svc
    on upper(trim(o.service_line)) = upper(trim(svc.opportunity_service_lines_desc))
left join ref_category as cat
    on upper(trim(o.category)) = upper(trim(cat.opportunity_category_desc))
left join ref_segment as seg
    on upper(trim(o.stage_name)) = upper(trim(seg.opportunity_segment_desc))
left join ref_business_line as bl
    on upper(trim(o.service_line)) = upper(trim(bl.opportunity_business_line_name))
left join ref_selling_team as stm
    on upper(trim(o.sales_lead)) = upper(trim(stm.opportunity_selling_team_desc))
left join ref_global_region as gr
    on upper(trim(o.region)) = upper(trim(gr.global_region_name))
```
